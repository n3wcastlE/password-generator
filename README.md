# Password Generator 🔒

This is a Python-based password generator with a GUI.

## Features:
✅ Generates strong passwords  
✅ Easy-to-remember password mode  
✅ Copies passwords to clipboard  
✅ Saves passwords to a file  
✅ Strength rating system (Weak / Medium / Strong)
